# App Ideas (Python)

Latihan dari daftar [app-ideas](https://github.com/florinpop17/app-ideas) karya Florin Pop, dikerjakan dengan **Python**. Dimulai dari Tier 1 (Beginner), lalu Intermediate dan Advanced.

Project logika murni berupa skrip Python dengan tes `unittest`. Project yang dekat dengan analisis data nanti berupa notebook Jupyter. Project yang memang visual tetap HTML/CSS/JS dan ada di [app-ideas-projects](https://github.com/alvrlfarfaraway/app-ideas-projects).

## Kebutuhan

Python 3.12 saja. Tidak ada library tambahan untuk skrip. Notebook butuh `pip install notebook`.

## Struktur

`1-beginner/<project>/` berisi kode, `test_*.py`, dan `README.md` tiap project. Jalankan tes dari dalam foldernya: `python -m unittest -v`.
